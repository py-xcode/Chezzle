# 新手引导关卡 · 设计文档 v3（多场景大远征）

> 架构：**一章一世界（Multiscene）**——不再是一条长廊隔间。每个场景是独立世界
> （尺寸/地形/大气各异），通过"门户开关"热切换，玩家对象全程随身携带
> （物品栏/血量/身上物质无缝保留）。**传送门第 5 章才首次登场**（"大仪式"场景）。
> 自写两个模组：**showtime（演出编排）** + **checkpoint 多场景版**（死亡回本世界复活）。
>
> 文案原则：直白、画面感、让人想往前走；**不用隐晦比喻、不抖机灵式自嗨**。

## 二、逐世界设计（含演出剧本）

### 世界 1 · 苏醒草原「走得动，就是胜利」
- **地形**：开阔草原；缓坡起伏、两条干涸小河沟（跳得过去）、一块大石（跳上去看风景→视野）。
- **玩**：移动/跳教学（横幅+路标双文案）；**大气教学**：走进草原中段，横幅"空气里飘着**氧气 O₂**——燃烧的秘密武器，先记住它"；HUD 空气面板可见。
- **出口**：草原尽头**巨石闸门** + **压力开关**："站上去，给闸门一个'开门'的信号"——闸门打开（演出：闸门开启的震屏+尘雾粒子），**热切换场景 2**。
- **演出**：开场横幅连播（见〇）；切场景瞬间横幅"第 2 世界 · 翡翠峡谷"。

### 世界 2 · 翡翠峡谷「换衣服 · 爬上去」
- **地形**：垂直峡谷：瀑布、三层平台、蓝色水池(CuSO₄)、孤高台塔、**塔旁的冰面地台**（暖色峡谷中的一块寒冰）。
- **玩**：
  1. 跳进蓝池 → **第一个化学反应**：NaOH+CuSO₄→Cu(OH)₂↓（反应标签+蓝色沉淀溅落——"化学反应：你的表面'换了一套蓝衣服'"）→ **Q 收集**（横幅教学）。
  2. **搭高**：高台塔跳不上去 → 横幅"**Shift 放沉淀**——往脚下放一把，把自己垫高！"（修复的柱状堆叠：8px 细柱、155px 垫高，现学现用）。
  3. **冰面（放这）**：塔旁冰台——路标"这层冰面滑得很：**沉淀放上去会滑走**，想在这搭积木？它会让你的积木满地跑。冰上只能'滑行'，搭不了高。"（旁边放一把 NaCl 沉淀给玩家试手——滑走效果当场可见）。
  4. 把 Cu(OH)₂ 放上**化学开关**（标注）→ 开关亮 → 门户开启。
- **演出**：跳池瞬间——反应标签+粒子溅落+池水变蓝的短震屏；搭高成功（垫高到塔顶）时横幅"上来了！化学家的梯子是沉淀"。

### 世界 3 · 炼丹台地「点灯 · 烤粉 · 变颜色」
- **地形**：台地阶梯；**一条灯光小道**（3 盏酒精灯依次摆放，每盏配压力开关）；加热台；**焰色台**（常燃灯+CuSO₄/NaCl 沉淀堆）。
- **玩**：
  1. **灯列**：站上开关→灯亮（"你踩的不是开关，是灯的**燃点**"）——三盏灯一路点亮，灯光指引出口方向（视觉动线）。
  2. 把 Cu(OH)₂（物品栏存货）放加热台灯上 → 分解 → **CuO**（"烤一烤，蓝色变黑色——受热分解"）。
  3. **焰色台**：把 CuSO₄ 粉放常燃灯上→**火焰变绿**；NaCl→**变黄**。"火焰调色台：放什么元素烧什么颜色——**它不消耗**，移开就还原。"
  4. CuO 放化学开关 → 门户。
- **演出**：灯列依次点亮（每盏一个开关灯亮的短震屏）；焰色变色瞬间大欢呼横幅。

### 世界 4 · 深井实验室「产气 · 飞出深井」（测验①）
- **地形**：**竖井**（从井口下降到井底实验室），**大气：无氧**（HUD 空气面板显示"空气稀薄"，横幅："这里的空气**没有氧气**——想点燃什么？先别做梦。"）井底实验室：盐酸池、Zn 块、气体探测器(H₂>0.25g 标注)、出口门。
- **玩**（测验①）：
  1. 把 Zn 块推进盐酸池 → **产 H₂**（反应标签 Zn+2HCl→ZnCl₂+H₂↑）。
  2. **气泡柱托升**：站上 H₂ 气泡柱 → 气流把你**从井底一路托回井口**（"氢气比你轻——它背着你飞"）——井口有出口门。
  3. **气体探测器**：井底探测器检测 H₂ 超标 → 亮红灯→ 出口门"咔"地解锁（"评委已就位：证明氢气真的存在"）。
  4. （彩蛋）火光不能点（无氧）——如果玩家把灯……（不教，纯氛围）。
- **演出**：入井下落(相机跟随)；产气托升的壮观气流+气泡；探测器亮起横幅"🧪 测验① 通过！"。

### 世界 5 · 爆炸盆地「点燃导火索」（测验② + 传送门首秀）
- **地形**：盆地：水池、Na 块（门口）+ 警告牌；**高架绳桥**（吊着 Zn 块的绳子横跨盆地）；酒精灯（"点火台"）；水池后方的高台探测器 + **紫色传送门一对（首次登场）**。
- **玩**（测验②·用户点名链路）：
  1. **警告横幅**："把门口的 Na 块**推进水池**——推完**快跑**！这次真的会炸。"
  2. 亲手推入 → **爆炸**（震屏+冲击波+碎渣——"物理课：能量守恒"）；**爆炸切断绳子** → 吊着的 Zn 块砸进盆地（"看！爆炸连绳子都不放过"）。
  3. 爆炸产 H₂ → 探测器 → **点燃！**（附近酒精灯亮着 → 大气 H₂+O₂ **爆鸣**——"轰！——看，氢气在氧气里烧起来就是这么干脆"）→ **检测器完全点亮 → 传送门激活**。
  4. **传送门首秀详解**：路标"紫色拱门=**传送门**。同色的一对互相连接：走进去，从另一扇出来。它只认'开关承认'——门不亮就是还没解锁。" → **走进传送门 → 世界 6**（热切换）。
- **演出**：爆炸→断绳→爆鸣的**连锁演出**（showtime 编排：震屏×N + 各方向粒子 + 横幅节奏）；传送门首次激活的紫色辉光+音画强调。

### 世界 6 · 溶液神殿「从水里拧出钥匙」
- **地形**：神殿（仪式感）：酸池、CuO 块、提取器+压力开关、**钥匙基座**、成对传送门(回归/前进)。
- **玩**：
  1. CuO 投入酸池 → 溶解成蓝色 CuCl₂ 溶液（"固体可以在液体里'消失'——溶解"）。
  2. 站上提取器开关 → 地表**冒出粉末** → Q 收集（"把盐从水里'拧'出来"）。
  3. CuCl₂ 粉放进**钥匙** → 钥匙亮（"钥匙是**永久锁**：放对了它就永远开着，不消耗——锁匠界的良心"）→ **传送门亮**。
  4. **传送门成对玩法**：神殿左右各一扇（同色）：一扇回世界 5（回头路），一扇前进（"传送门也有'单向出口'——看清楚再进"）。
- **演出**：钥匙开锁辉光+神殿光柱；入门切换横幅。

### 世界 7 · 火山口「最后的点火」（通关+庆典）
- **地形**：火山口（大）：发光的岩浆池（装饰）、**双氧水池 + MnO₂ 块**、常燃灯 + C 块、**喷灯**（高温，灯上预置 CuO+C）、巨门+压力开关。
- **玩**：
  1. MnO₂ 推入双氧水池 → **催化制氧**（气泡）——"催化剂帮你把氧造出来，它自己一根毛都不掉"。
  2. C 放灯上 → **燃烧**（C+O₂→CO₂）——"还记得草原的氧气吗？它就在这烧碳"（氧气教学闭环）。
  3. 加餐：喷灯还原 → Cu（"把喷灯上的 CuO 烤成铜——收藏！"）。
  4. **毕业考**：站上开关 → 巨门开启 → 走进光里 → **通关**。
- **庆典演出**（showtime）：
  - 通关瞬间——**烟花秀**：连环彩色爆炸（用引擎的焰色染色：Na 黄 / K 紫 / Cu 绿 / Li 红轮流）+ 震屏节奏 + 大横幅"🎉 恭喜通关！你已是正式的化学怪人"。
  - （技术力：烟花 = 引擎爆炸系统的焰色集合染色，一个模组一句 `fireworks()` 搞定。）

## 三、自写模组（技术力展示）

### 模组 1 · showtime（演出编排）`docs/plugins/showtime.js`
一段**声明式剧本**跑完整关演出：
```js
showtime(scene, M, {
  scenes: [
    { id: 'plain', enter: [banner('嘿！你好！'), banner('...'), ...] },
    { id: 'basin',  open: 'detH2', do: [banner('测验②通过！'), fireworks(12), switchTo('temple')] },
    { id: 'crater', win: [fireworks(30), banner('🎉 恭喜通关！')] },
  ],
});
```
- 触发器：`enter`（进入场景）/ `open`（指定开关开启）/ `pos`（玩家进入区域）/ `win`；
- 动作：`banner(文字, 秒)` / `shake(强度)` / `fireworks(发数)`（焰色爆炸，`fire('explosion')` 染色）/ `switchTo(场景)`；
- 用引擎原生能力：`showBanner` / `camera.shake` / `explode`（焰色集合）/ `Multiscene.switchTo`——**不碰任何私有字段**。

### 模组 2 · checkpoint 多场景化 `docs/plugins/checkpoint.js`（升级）
- cfg.spawns 支持 `scene` 字段（哪个世界的检查点）；
- watch 只登记**当前激活场景**的检查点；死亡后复活在**发生死亡的世界**的最近检查点；
- 跨世界死亡（如掉进岩浆）也正确复活；复活横幅幽默随机（"复活！化学家从不回头看爆炸"）。
