## 1. 游戏整体内容、功能与玩法

### 1.1 定位

纯 H5 的 2D 化学解谜游戏（"Chezzle"），高中化学范围、数据驱动。
**零外部依赖**：原生 ES Modules；`node tools/build.mjs` 打包为单文件 UMD
（`dist/chezzle.js`，全局 `Chezzle`）。浏览器 <canvas> 渲染，无框架、无资源文件。

### 1.2 核心玩法循环

1. 玩家（默认 NaOH，血量 = 自身质量）在 2D 世界里移动/跳跃；
2. 用**药品池**（预置溶液）、**物块**（各种化学物质）、**装置**（灯/开关/滴管/集气瓶…）触发反应；
3. 产物（沉淀/气体/溶液变化）反过来改变世界——沉淀可搭路垫脚、气体可飘起/压人/爆鸣、溶液变色/变浑/显色；
4. 达成关卡目标（开门、点亮、检测气体、通关门…）。

### 1.3 面向玩家的功能清单

**玩家控制（键位）**

| 键 | 作用 |
|---|---|
| A / D | 左右移动 |
| 空格 | 跳 |
| Q | 收集（附近沉淀粒子/容器内沉淀颗粒——按颗粒位置就近收集） |
| Shift | 放置（选中物质格→0.5g 就近放入脚下容器/附近灯/地面；选中物品格→放置物品到身旁） |
| C | 物品栏交互：空格→拾取最近可携带物品；烧杯格→吸液 20g；空滴管格→吸液 5g；按住 C（集气瓶格）→收集最近气泡柱产气 |
| X | 烧杯格→全部倒入最近烧杯/池；按住 X（集气瓶格）→向最近液体容器通气 0.05g/s |
| R | 重开本关 |
| 鼠标左键 | 点击/按住/拖动**滴管**：单击=滴一滴、按住=0.08s/滴持续滴、玩家附近按住拖动=挪位置（移动>6px 判定为拖，不滴） |
| 鼠标点击 | HUD：右上提示按钮、右下物品栏选格 |

**物品栏**：5 格。物质按种类分格（每格 100g 上限，跨格收集）；**物品格**（集气瓶/烧杯/滴管）一物一格**不堆叠**（空物也占格），与物质互不干扰。

**化学系统（核心卖点）**

- 120+ 种物质（`CHEM_REFERENCE.md`）：酸/碱/盐/金属/非金属/氧化物/气体/指示剂/焰色；
- 四层反应体系：L1 氧化还原（自动配平）→ L2 离子双置换 → L3 类别规律 → L4 特例表；另有关卡自定义反应（最高优先级）；
- **溶液**：溶质按质量存储、水单独跟踪、pH 计算、指示剂显色（石蕊/酚酞/甲基橙）、离子显色（Cu²⁺ 蓝绿等）；
- **微溶体系**（近期重点）：`solubilityLimit`(g/L) + 过饱和带（1.25×）；溶液渲染有**浑浊度**（浓度/饱和线→渐浑乳白），**先浑浊、过饱和带后才出沉淀颗粒**；`Solution.add` 触发 `onOversaturate` → 容器 `addPrecipitate`；
- **气体**：产气 → 气泡柱（GasColumn，按摩尔质量上浮/下沉，对玩家/物块施力）+ 大气模型（O₂/CO₂ 百分比 HUD；可燃气体爆鸣）；碱吸收酸性气体（石灰水检验 CO₂）、气体溶解水（H₂CO₃/氯水/氨水…）、固体碳化（NaOH 玩家被 CO₂ 碳化掉血）；
- **爆炸**：14 瓣多层火球 + 冲击波（玩家/物块/沉淀被炸飞、碎裂掉渣）+ 屏幕震动 + 焰色集合（反应物+溶液溶质 的焰色，≤3 种轮流上色）；
- 玩家：接触同类物质量回血；表面附着产物（壳）；溶解、碳化、脱落（走路掉渣）等。

**物理系统**

- 固体 = "网格计算法"（5px 格，0.1g/格）：腐蚀/生长随化学反应真实改变形状与碰撞箱（多矩形贴合）；
- 池/烧杯壁=静态/动态碰撞体；玩家可推动烧杯、可在沉淀堆上**垫脚/叠高**（自动上台阶 14px）；
- 气柱托举/下压（noLift 标记豁免）；爆炸冲击；绳子悬吊/炸断；传送门。

**物件清单**（多数可在编辑器中放置并导出 DSL）

地板、药品池(Pool)、物块(Block)、沉淀堆(Deposit)、玩家、酒精灯、喷灯、开关（化学/压力两种）、钥匙/门、路标、传送门、气体探测器、提取器、烧杯(Beaker)、滴管(Dropper)、**集气瓶(GasBottle，本轮新增)**、气流柱、绳子、气泡、火花、爆炸、反应标签、液滴(Drip)动画。

**可携带物品体系（本轮新增）**——集气瓶/烧杯/滴管：

- 拾取（C，空格）→ 携带（连同内容物）→ 放置（Shift）到身旁；烧杯可推动、滴管/集气瓶无碰撞箱；
- 吸液/倒出/通气全程走"最近容器"（按**边缘间隙**距离，贴边即可）：
  - 烧杯：C 吸 20g/次（同比例样品，水+溶质一并转移、可混合、满容积封顶——标准 200g）
  - 滴管：C 吸 5g/次（取占优溶质/纯水 H₂O；**已装液不能再吸**）
  - X：烧杯全部倒入最近的烧杯/池（烧杯按容量封顶、池敞开；满杯自动回退下一个）
  - 集气瓶：按住 C——最近气泡柱产生的气体**直接截留进瓶、不进大气**（5g 封顶，瓶满恢复原管线）；按住 X——0.05g/s 通气到最近**有水**容器（气泡从注入点冒出；CO₂→石灰水变浑析 CaCO₃、CO₂+水→H₂CO₃、Cl₂→氯水等；主动鼓泡时 CO₂/SO₂/NO₂/Cl₂ 也可溶水）
- 液面随量：烧杯/池渲染高度 = 实际液体量/容量（吸出/倒入水面升降可见）。

**关卡与编辑器**

- `tools/leveleditor.html`：可视化编辑器（拖放、属性面板、试玩、存档 localizationStorage）→ 一键导出可运行关卡 HTML（内置 `LevelBuilder` DSL 链式脚本）；
- 编辑器目录本轮新增：集气瓶（容量/初始气体 JSON）、烧杯 `water` 字段（0=空杯）、滴管 `liquid` 字段（0=空管）；
- 调试模式（`.debugmode()` / 试玩默认开启）：F5 暂停、F6 步进、X 切换悬停重叠、悬停显示来源（关卡生成/反应生成/玩家放置…）；HUD 空气计/气体变化日志/最近反应/爆炸原因。

**插件系统**：关卡脚本事先注入（`onTick/wait/interval/onKeyDown` + 组件注册），见 `docs/plugin-api.md` 与 `docs/plugins/*`。

### 1.4 开发约定（用户明确要求，务必遵守）

- **永远不要私自删除内容**（如自动踮脚等已确认特性，只能增强不能砍）；
- **遇到 bug 先复现，不要乱猜原因、不要"粗暴治标"**——用最小场景复现 + 定位根因再改；

## 4. 最近几条用户消息（原文，按时间从近到远）

**⑤（最新，本次已完成）可携带物品大特性：**
> 接下来来做一个原版的新特性，方便玩家收集气体，液体。这次更新内容比较大。
> 首先要加入一个新的东西，集气瓶。它可以收集气体，并且可以模拟向溶液中通入气体。
> 1.玩家可以和收集沉淀一样，在背包中放入集气瓶，烧杯，滴管。玩家可以**选中一个空的格子**，然后按下"c"，来收集最近的一个这类物品。这些物品都不可以堆叠，即便他们都是空的。
> 2.收集液体：玩家可以选中带有**烧杯，*空*滴管**的格子，然后按下c，这将会把距离玩家当前位置最近的药品池中的一部分液体转移到玩家选中的格子的容器中。烧杯每次转移20g，烧杯最大容量200g，滴管每次转移5g，最多50g。注意同一个烧杯只要没满就可以加新的液体（混合在一起，和现实一样），滴管则不行（现实中无法向装有物质的滴管中直接加入新的液体）。
> 3.把液体转移到容器中：对于烧杯，玩家可以按下x键，来把其中的物品加入到距离自己最近的烧杯/药品池中。滴管不行。
> 4.放置烧杯/滴管物体：按下shift键可以放置烧杯和滴管。（在玩家附近）其中，烧杯是本身就可以推动的。滴管一般被认为是没有碰撞箱的。在距离玩家自身一定距离内，玩家可以拖动滴管来改变其位置。
> 5.收集气体和放置气体大部分流程和上述相同，但是收集这里：放入物品栏之后，要一直按下c键。此时，会选定距离玩家最近的一处气泡柱。然后，根据此处产生气体的速度进行收集，反应产生的所有气体不再进入大气，而是进入集气瓶。集气瓶最多收集5g气体。通入气体同样长按，通入气体时速度为0.05g/s。集气瓶和烧杯同理可以放置。

**④ 微溶析出体验（已随 ③/② 一同完成）：**

>
